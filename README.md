The safety warning label that should come printed on every human being: **"WARNING: This human will ignore all instructions, blame the Wi-Fi, and ask the AI to redo it at 2 a.m."**

## Run

```sh
python3 main.py
```

Writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
